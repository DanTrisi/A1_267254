Repository for the code and the report of the first assignment of the course "Optimization and
Learning For Robot Control" at University of Trento by Professor Andrea DelPrete.

This project is developed by Daniele Trisotto and Michele Macellari.

This folder contains everything, but to submit just the python code and the pdf report
use the following command:

```bash
git archive --format=zip --prefix=A1_267254_267255/ -o ~/A1_267254_267255.zip HEAD -- '*.py' '*.npz' report/report.pdf
```
